Method 1: Direct Preset Fault Buttons

  1. Choose a Target Task (e.g. Auth Token Expiration Fix).
  2. Click one of the fault buttons: TRUNCATED_DIFF, SYNTAX_CORRUPT, TOOL_TIMEOUT, or FLAKY_TEST.
  3. Click 🚀 Launch Sentinel.
  4. Watch Sentinel sandbox the run, detect the failure in the Verifier, trigger automatic rollback via Git (git checkout -- .), and recover on the next attempt!

Method 2: Manually Inject Faults into Agent Code

  1. Scroll down to the Workspace Git Diff / Code Editor in the right panel.
  2. Edit the code manually:
    • Cut syntax (remove closing parentheses or colons)
    • Prepend garbage characters or unclosed strings
    • Insert time.sleep(5) to trigger timeout watchdog
  3. Set the Fault selector to NONE (so Sentinel doesn't auto-corrupt; it tests your exact edits).
  4. Click 🚀 Launch Sentinel. The Verifier deterministically catches your custom sabotage and recovers!
  5. Click ↺ Reset Code to Healthy Baseline anytime to restore genuine fix code.
